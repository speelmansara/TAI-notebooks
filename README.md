# Techniques of AI — Exercise Sessions

Notebooks for the exercise sessions of the Techniques of AI course. There are 4 lectures, each with a corresponding notebook.

## Running the notebooks

- **Google Colab**: open any notebook directly in Colab, no setup required.
- **Locally, in your own IDE**: set up a virtual environment with the dependencies in `requirements.txt` — see the [Python venv quickstart guide](python_venv_quickstart.md).

## Notebooks

| Notebook | Topic |
|---|---|
| [notebook-1-ML_crash_course.ipynb](notebook-1-ML_crash_course.ipynb) | Practical introduction to machine learning with Python |
| [notebook-2.ipynb](notebook-2.ipynb) | Preprocessing & model training on real sensor data |
| [notebook-3.ipynb](notebook-3.ipynb) | Classification with the scikit-learn breast cancer dataset (decision trees, random forest, XGBoost) |
| [notebook-4.ipynb](notebook-4.ipynb) | Intro to Weights & Biases with an MLP neural network |

A [notebook-0-preliminaries.ipynb](notebook-0-preliminaries.ipynb) notebook is also included as an optional refresher on NumPy & Pandas.

Solution notebooks are provided alongside each exercise notebook (`*-solution.ipynb`).
